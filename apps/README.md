# 软件（apps）

当前版本：**V0.2.6**（V0.3.0 从 AI GP 开发开始）

版本号定义在根目录 `CMakeLists.txt` 的 `project(... VERSION x.y.z)`，编译后显示在程序侧边栏和窗口标题上。每次发布在下面的版本记录里加一节。

## 组成

| 目录 | 内容 |
|---|---|
| `telemetry-core/` | F1 25 UDP 遥测包结构（2025 格式），头文件库，所有程序共用 |
| `dash-app/hub/` | 遥测转发中心：接收、转发、录制（`.f1tr`）、回放；附命令行 `f1hub` |
| `dash-app/timing/` | 比赛状态：排名、赛段、相对差距、踏板和转速，与界面无关 |
| `dash-app/sim/` | 虚拟比赛：按官方包结构生成遥测，没有游戏时演示和测试 |
| `dash-app/tracks/` | 24 条赛道的内置轮廓（中心线 + 宽度）和对齐到游戏坐标的算法 |
| `dash-qt/` | `LyttonTelemetryTool.exe`：Qt Quick 桌面外壳（QML 布局 + `ImCanvas` 嵌入原界面）、头显面板线程、SVG 赛车 |
| `dash-app/race/` | 原界面与 HMD 面板代码；`LyttonClassic.exe`（旧 ImGui 窗口）：遥测工作站（实时仪表、采集、回放、回放对比、转发）+ HMD 面板（SteamVR 叠加层） |

架构、构建方法和设计约束见 [docs/ARCHITECTURE.md](../docs/ARCHITECTURE.md)。

## 使用

1. 安装：运行 `LyttonTelemetryTool-Setup-0.2.6.exe`（装到用户目录，不需要管理员权限；覆盖安装保留设置和录像）。
2. F1 25 设置 → 遥测：UDP 开，IP `127.0.0.1`，端口 `20700`，格式 2025。
3. 运行 Lytton Telemetry Tool；要用头显仪表就先启动 SteamVR。没有游戏时用“Lytton Telemetry Tool（虚拟比赛演示）”快捷方式或 `--demo`。
4. 实时仪表右上角“开始录制”；录像在“回放设置”里回放，在“回放对比”里任选两圈对比。
5. 程序内置 hub：监听 20700，按“遥测转发”页的设置转发给其他工具。

不注入游戏、不改游戏文件，在线模式（含双人生涯）也能用。设置（`lytton.ini`）、日志（`lytton.log`）和录像保存在程序目录；程序目录不可写时保存在 `%LOCALAPPDATA%\LyttonTelemetryTool`。

### V0.2.6 — 2026-11-11

- Game 页新增“方向盘按键”（WHEEL BUTTONS）。按 SimHub 的思路把“动作”和“按键”分开：插件和动作在 `race/wheelinput.cpp` 的表里登记，页面按表自动列出；**每个插件单独选择自己的设备**（比如方向盘给 Lytton Dash、按键盒给以后的功能）。现有插件是 Lytton Dash，动作是第一页、第二页。配置文件每个插件一段（`[lytton_dash]`）。选择设备，给“第一页”“第二页”各绑一个键（点 Bind 再按方向盘上的键，旋钮左右两个方向也可以），实时显示按下的键。存到 `%LOCALAPPDATA%\LyttonTelemetryTool\wheel_buttons.ini`，Lytton Dash 在游戏里约 1 秒内读到。
- 回放对比：图表区可滚动。展开的图表每张至少 120 像素高，放不下时出现滚动条；在标题行或空隙上滚滚轮、或按住 Shift 滚滚轮滚动，在图表上滚滚轮仍是缩放。

- Lytton Dash：方向盘屏幕配色提到最亮（游戏按场景光照显示屏幕，阴影里饱和色发暗）；Page button 上限改为 100（Swofty 滑块最多 100 步）。
- 待测项已在游戏电脑上实测通过。

### V0.2.0 — 2026-11-06

**主界面重构**：侧边栏导航，以遥测采集和回放为主。
- 实时仪表：名次 / 圈数 / 当前圈 / 上一圈 / 个人最佳 / 全场最佳，车辆（速度、档位、换挡灯、踏板、方向、DRS、ERS、燃油），四轮温度 / 胎压 / 磨损 / 刹车温度，最近 30 秒曲线，赛道位置条和当前圈赛段，完整排名表。
- 回放对比（取代原“圈速分析”页）：从录像里任选两圈（同一个文件或不同人的录像），位置对齐（按圈内距离，差值为时间差）或时间对齐（按圈内时间，差值为距离差）。赛道地图显示两人的行车线和同一时刻两车的位置（三角箭头指向车头方向，可缩放、拖动），赛段对比表，速度 / 油门 / 刹车 / 档位 / 转速 / 方向 / 差值曲线共用光标；底部进度条播放对比圈，两车同步前进。
- 地图上的车辆改为三角箭头，方向取自 Motion 包的车头朝向。
- 数据采集：数据源切换（实时遥测 / 虚拟比赛 / 录像回放），各类包的频率与累计。
- 录制：只由实时仪表页右上角的按钮开始和停止（实时遥测和虚拟比赛都可以录）。游戏暂停（会话时间 0.3 秒不走）或超过 1 秒没有数据时自动暂停，不写入、录像里不留空白，数据恢复后接着录。
- 数据回放：录像库（时长、大小、包数，回放 / 删除），暂停、±10 秒、拖动进度条、0.25～16 倍速，进度条上标出每圈起点；回放时其他页面底部有播放条。回放页的进度条分两级：全场总览（圈标签按圈数自动稀疏，方框标出第二级的范围）和最近几圈的细节条（默认 5 圈，可选 3 / 4 / 5 / 8，每圈标出圈号和圈速，跟随播放，拖动时不动）。点击当前时间可直接输入时间跳转（如 12:30、1:05:00、90 秒；全角冒号也可以），回车或点别处确认，Esc 取消。
- 遥测转发：hub 转发目标在界面里增删改、启用 / 停用，立即生效；每个目标的速率、已发送、错误数。
- 实时仪表新增：赛道俯视图（用自己车的 Motion 坐标画出轮廓，按本圈赛段着色，标出 S2/S3 分界和全场车辆位置），赛段成绩和对比最快圈的实时差放在地图一侧。
- 车辆状态：动力单元六个部件磨损、变速箱 / 发动机损伤、前翼左右 / 尾翼 / 底板 / 扩散器 / 侧箱损伤（车身示意图着色），DRS / ERS 故障、爆缸 / 卡死，故障与恢复、受损与修复的事件记录。
- 油耗：遥测只给油箱余量，按余量随时间的变化算出瞬时油耗（g/s、kg/百公里）、本圈已用、上一圈、平均每圈和可跑圈数。
- 轮胎与车辆状态合为一块（中间下方）：俯视车身图上的四个车轮按表面温度着色（中间细条为内部温度，变暗和下方数字为磨损，外框为路面），气动部件按损伤着色；每个轮胎的温度、载荷、滑移率、滑移角、胎压、刹车温度、路面标在车身两侧（游戏数据，MotionEx / CarTelemetry）；右侧为动力单元磨损、故障和事件。最近 30 秒曲线移到左下。
- 地图缩放：滚轮缩放（1～24 倍，放大时以本车为中心并跟随），左键或右键拖动平移（“回到本车”恢复跟随），双击或“全图”回到全赛道；放大后显示本圈（白）和最快圈（紫）的行车线。
- 侧边栏“数据采集 / 数据回放”更名为“采集设置 / 回放设置”。
- 界面比例锁定：按 1920×1009（开发机最大化窗口）布局，整体等比缩放到实际窗口，宽高比不同时两侧或上下留边；字体按启动时的缩放倍数生成；程序声明 DPI 感知，高分屏不再被系统拉伸发虚。
- 赛道地图：按 Session 包的赛道编号加载内置赛道数据（24 条赛道 + 3 条反向，中心线和左右边界），自动与游戏坐标对齐；没有数据或对不上时退回显示行车线。赛段分界用游戏给的距离。
- 赛道限制：以游戏判定为准（切弯警告、总警告、罚时、本圈无效），在地图上标出发生位置；另外标出两个以上车轮压到草地 / 碎石等的位置。
- 遥测包新增 Session（1，已用真实抓包验证）、Motion（0）、MotionEx（13）结构。
- 虚拟比赛：没有游戏时生成符合官方包结构的 20 车比赛数据，录制、回放、转发、HMD 面板全部可用。

**遥测**

**HMD 面板**（全部跟随头部，约 1 m 远，贴视野边缘）
- 排名（左上角）：精简 6 行（领跑、前两位、自己、后两位；领跑或末位时连续 6 位），差距默认相对自己（自己 +0.000，前车负、后车正，可切换为与前车 / 与领跑者），自己一行白底高亮，轮胎类型和使用圈数，全场最快圈标记。
- 赛段（右上角）：当前圈时，S1/S2/S3 按全场最快（紫）/ 个人最快（绿）/ 较慢（黄）/ 无效（红）着色，各段个人最佳，上一圈 / 个人最佳 / 全场最佳。
- 油门刹车（下边缘）：一条连续进度条，刹车（红）从中线向左、油门（绿）向右点亮，斜切分段；两端上方显示百分比，中间框内显示发动机转速，颜色随换挡灯变化。

- 从 SteamVR 读取型号、每眼视场、屏幕外倾、推荐渲染分辨率；面板贴双眼重叠区边缘，纹理分辨率按像素/度自动提高。可在 `f1-race.ini` 用 `hmd.*` 手动指定。

**客户端**
- 每块面板相对基准位置的偏移（左右 / 上下 / 远近 / 转角 / 仰角 / 缩放），背景与信息透明度分开调，设置自动保存。
